Politique de confidentialité / Privacy Policy

Dernière mise à jour / Last updated : 17/11/2026

Qui sommes-nous / Who we are

Petit Cerveau Studio est un outil privé utilisé par l'auteur de la chaîne « Professeur Petit Cerveau » pour publier ses propres vidéos. Contact : lispheraa@gmail.com.

Petit Cerveau Studio is a private tool used by the author of the "Professeur Petit Cerveau" channel to publish their own videos.

Données traitées / Data we process

  • Jetons d'accès OAuth fournis par TikTok, Google (YouTube) et Meta (Instagram) lorsque le propriétaire du compte autorise l'application. / OAuth access tokens issued by TikTok, Google (YouTube) and Meta (Instagram) when the account owner authorizes the app.
  • Informations de base du compte (identifiant, nom affiché) via TikTok Login Kit (user.info.basic), afin de vérifier le compte connecté. / Basic account info (open ID, display name) via TikTok Login Kit (user.info.basic), to confirm which account is connected.
  • Les vidéos et légendes produites par l'outil, envoyées sur les comptes de la chaîne (TikTok : video.upload, en brouillon). / Videos and captions produced by the tool and uploaded to the channel's accounts (TikTok: video.upload, as drafts).
  • Statistiques publiques et privées des vidéos de la chaîne, pour mesurer leurs performances. / Statistics of the channel's own videos, to measure performance.

Utilisation et conservation / Use and storage

Les données sont stockées uniquement sur le serveur personnel de l'auteur, ne sont ni vendues, ni partagées, ni utilisées à des fins publicitaires. Aucune donnée d'autres utilisateurs n'est collectée. L'utilisation des données obtenues via les API Google respecte la Google API Services User Data Policy, y compris les exigences d'utilisation limitée (Limited Use).

Data is stored only on the author's personal server and is never sold, shared, or used for advertising. No data from other users is collected. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Suppression / Deletion

L'autorisation peut être retirée à tout moment depuis les paramètres de TikTok, de Google (myaccount.google.com/permissions) ou d'Instagram ; les jetons correspondants sont alors supprimés du serveur. Pour toute demande : lispheraa@gmail.com.

Access can be revoked at any time from TikTok, Google or Instagram settings; the related tokens are then deleted. Requests: lispheraa@gmail.com.
